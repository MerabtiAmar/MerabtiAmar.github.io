# merabtiamar.github.io

Source de mon site personnel : [merabtiamar.github.io](https://merabtiamar.github.io) (version anglaise : [/en/](https://merabtiamar.github.io/en/)).

Site statique en HTML, CSS et JavaScript, sans framework, sans étape de build et sans ressource externe, publié par GitHub Pages depuis la branche `main`.

```
index.html                 carnet : expériences, parcours, atelier, ce que je cherche, contact
experiences/               une page par expérience détaillée
en/                        version anglaise (mêmes pages)
assets/css/site.css        styles (thème clair et sombre, polices auto-hébergées)
assets/js/site.js          mode 30 secondes, filtres, tableau tactique, diagraphie du parcours (FR/EN selon la langue de la page)
assets/js/football.js      moteur de football et politique PPO portés en JavaScript (dépôt rl-football-selfplay)
assets/data/politique.js   poids de la politique (float16, base64) : les matchs sont joués dans le navigateur
assets/fig/                figures reprises des dépôts de projets
assets/fonts/              Newsreader et IBM Plex Mono (licence SIL OFL, textes joints)
assets/img/                portrait, photos, favicon et images d'aperçu pour les réseaux sociaux
cv/                        CV en PDF
```

Pour le consulter en local, ouvrir `index.html` dans un navigateur.

Les textes et les photos sont © Amar Merabti, tous droits réservés. Les polices restent sous leur licence SIL Open Font License.
